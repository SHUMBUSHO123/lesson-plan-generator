Manual Payment / Code Submission
How to pay manually via MTN:
  1. Dial *182*8*1*1944115*AMOUNT*PIN# from your MTN number registered under ISOMOPLUS.
  2. Enter the amount corresponding to your selected plan:
    • Weekly → 200 RWF
    • Monthly → 500 RWF
    • Term → 1000 RWF
  3. Confirm the transaction and note the payment code you receive.
  4. Return to this page and enter the code below to submit for admin approval.

Alternatively, contact admin via WhatsApp or call YOUR_NUMBER to get your payment code.
